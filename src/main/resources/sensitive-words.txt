# 敏感词库
#
# 格式：每行一个词；# 开头为注释；空行会被忽略。
# 位置由 studio.post.sensitive-words-location 配置，支持 classpath: 与 file: 两种前缀，
# 因此运营期可以直接指向服务器上的文件（file:/data/runshi-studio/sensitive-words.txt），
# 增补词库不用重新发版。
#
# 匹配行为（由 AcAutomaton 保证，写词时不必为变体单独建词条）：
#   - 全角与大写会被归一化，写 mlgb 就能命中 ＭＬＧＢ / MLGB；
#   - 中间插入的干扰符（空格 * - _ . , ~ + · | /）会被跳过，
#     写「敏感词」就能命中「敏*感 词」这类规避写法；
#   - 字母与数字**不会**被跳过，避免把正常英文撕碎造成误命中。
#
# 注意：空行与空白行会被忽略，不会导致「匹配一切」。
